# 🧠 NLP Assignment 3 – N-gram and RNN-Based Language Modeling

This project implements N-gram, RNN, LSTM, and Bi-LSTM models to perform next-word prediction on advanced datasets like WikiText-103.

## 👨‍💻 Team Members
- mariam: Data preprocessing & N-gram modeling
- rokaia: RNN & LSTM modeling
- ramez: Bi-LSTM & evaluation analysis

## 📂 Project Structure
- `data/`: Processed datasets
- `models/`: Model implementations
- `notebooks/`: Jupyter Notebooks for development
- `results/`: Visualizations and evaluation metrics
- `utils/`: Preprocessing and utility scripts
- `report/`: Final report and video demo
- `main.py`: Main script to run and evaluate models
